# To-Do App

REST API для управления списком задач, написанный на **FastAPI** с использованием **SQLAlchemy** и **PostgreSQL**.

Проект построен по слоистой архитектуре: роутеры → сервисы → репозитории → база данных. Каждый слой отвечает только за свою часть работы, поэтому код легко читать, тестировать и расширять.

## Возможности

- Получение списка всех задач
- Создание новой задачи
- Редактирование задачи (название и/или статус выполнения)
- Удаление задачи
- Автоматическое создание таблиц в БД при запуске приложения
- Настройка CORS через переменные окружения

## Технологии

- Python 3.14.7
- FastAPI
- SQLAlchemy 2
- PostgreSQL + psycopg 3
- Pydantic — валидация данных и схемы
- python-dotenv — загрузка настроек из `.env`
- Poetry — управление зависимостями
- black, isort, flake8 — форматирование и линтинг


## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/nastiikkk/to-do-app.git
```

### 2. Установите зависимости

Понадобится Python 3.14+ и Poetry.

```bash
poetry install
```

### 3. Создайте базу данных PostgreSQL через Docker

```bash
docker run -e POSTGRES_PASSWORD=admin -p 5432:5432 -d postgres
```

### 4. Настройте переменные окружения

Скопируйте пример и заполните значения:

```bash
cp .env.example .env
```

| Переменная          | Описание                                  | Пример                                                  |
| ------------------- | ----------------------------------------- | ------------------------------------------------------- |
| `DATABASE_URL`      | Строка подключения к PostgreSQL           | `postgresql+psycopg://user:password@localhost:5432/todo_db` |
| `CORS_ALLOW_ORIGIN` | Адрес фронтенда, которому разрешены запросы | `http://localhost:3000`                                 |

### 5. Запустите приложение

```bash
poetry run uvicorn main:app --reload --port 8080
```

Сервер будет доступен по адресу <http://127.0.0.1:8080>.
Таблицы в базе данных создаются автоматически при первом запуске.


## Архитектура

Запрос проходит через несколько слоёв:

```
Клиент → Router (api) → Service → Repository → PostgreSQL
```

- **Router** - принимает HTTP-запросы, валидирует данные через Pydantic-схемы и преобразует ошибки в HTTP-ответы.
- **Service** - бизнес-логика, управление транзакциями (`commit`), бросает доменные исключения (например, `TaskNotFound`).
- **Repository** - единственное место, где выполняются запросы к таблице `tasks`.
- **Models / Schemas** - ORM-модели для БД и Pydantic-схемы для API.
